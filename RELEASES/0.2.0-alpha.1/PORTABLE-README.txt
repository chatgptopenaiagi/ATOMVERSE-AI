ATOMVERSE AI 0.2.0-alpha.1 | The Living Universe
Experimental Windows 11 x64 prerelease. Unsigned.

Extract the entire ZIP and open ATOMVERSE-AI/ATOMVERSE-AI.exe.
Keep _internal and the executable together. No installer or global runtime
replacement is needed. Local history lives in %LOCALAPPDATA%/ATOMVERSE-AI.

Start live observer enables the sources displayed in Settings. Sampling is
off on startup. Stop live observer ends collection; Pause motion only freezes
animation. Closing the application stops its owned workers.

Drag to rotate, right-drag to pan, scroll to zoom. Select a particle to inspect
its event and retained history. System Observer shows numbers; Process Galaxy
shows observed identities and relationships. Computational Memory replays
recorded events and verifies SQLite integrity. Export view saves current data.

OBSERVED = measured source data. DERIVED = calculated values with inputs.
AI_INTERPRETED = optional model text/hypotheses. SIMULATED = synthetic demo.
UNAVAILABLE = no reliable reading. Visual energy is dimensionless.

Legacy records are backed up before migration and protected from rolling
retention. Default rolling limits are 10,000 rows and one hour; the row cap
may retain less time. A migrated v2 database requires this new application.
The preserved v1 backup can be opened by the previous application.

GPU telemetry requires an existing NVIDIA driver. GPU benchmarks require an
explicitly selected existing CUDA/PyTorch Python. Neither is bundled.
Local AI requires an already running loopback model server; no model is
downloaded or automatically started. Select a hardware particle for a small
evidence summary. Inference has a 90-second deadline and can be cancelled.

CPU temperature, reliable per-process GPU utilization/VRAM and verified disk
latency are unavailable. Process selection is bounded; omitted processes are
not assumed terminated. AI hypotheses never execute commands or repairs.

Process names and explicitly imported text may be private. Review exports
before sharing. No keystrokes, browser contents or command lines are captured.
