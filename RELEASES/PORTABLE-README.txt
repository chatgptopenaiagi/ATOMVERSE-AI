ATOMVERSE AI 0.1.0-alpha.1 — experimental Windows x64 development build

Extract the entire ZIP, then open ATOMVERSE-AI.exe inside its folder.
Keep the adjacent _internal directory and license files together.

Start with the visibly labeled synthetic demo. Click Sample hardware for real
observations, or Import ARX / JSON to select an ARX machine report (schema 0.1).
Drag to rotate, right-drag to pan, scroll to zoom and click a particle to inspect.

Benchmark Arena provides a bounded CPU matrix workload. GPU benchmarking needs
an existing CUDA-capable PyTorch Python executable selected in Settings. PyTorch
and CUDA are not included or automatically installed.

Knowledge Memory provides replay. Data Tables provides inspectable measurements.
Export view writes JSON or CSV. Hardware polling is off until explicitly enabled.
The optional AI view requires a separately running local model endpoint.

Memory/settings live under %LOCALAPPDATA%\ATOMVERSE-AI. Nothing is installed as a
service. The application does not modify ARX or existing AI environments.

This is an unsigned development build, not a finished intelligence platform.
